# Replication of Folbre & Smith (2017): Wage Inequality in Care Industries

## Description
This project replicates key findings from Folbre and Smith (2017) using CPS ASEC 2015 data. It focuses on analysing wage inequality in care industries through empirical methods.

## Data
The data used for this replication is from the CPS ASEC 2015 dataset, obtained via IPUMS CPS.
Due to licensing restrictions, the dataset is not included in this repository. However, it can be accessed from the IPUMS CPS website.

## Methodology
- Data cleaning and preprocessing of CPS microdata  
- Construction of variables (wages, occupation, demographics)  
- Replication of descriptive tables  
- Estimation of OLS regression models
- Replication of descriptive tables and regression results from the original paper

## Tools Used
- R (dplyr, haven, modelsummary, estimatr)

## Files
- Replication_Paper.pdf – Written analysis and results  
- Replication_Code.R – Full replication code
